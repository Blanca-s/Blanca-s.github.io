The learning of every LLM field beginner all begins with the study of Trasnformer. However, reading blogs about Transformer and taking notes are not enough, for technique details can only be reached in the practical implementation of it. 

This project based on the code provided by Harvard NLP group and armed with my own comments on it. Because the whole project was initially written to assist my own understanding on Transformer, I almost commented on each coding detail and draw figures based on my own understanding instead of directly using figures from other blogs or text books.
